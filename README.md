# 1C:Jet (Español)

> This is the regional version for Spanish-speaking countries of [1Ci-Company/Jet](https://github.com/1Ci-Company/Jet),  
> an educational open-source application built on the 1C platform.

---

## About the global 1C:Jet project

**1C:Jet** is an application built on the 1C platform, designed for beginners learning 1C development.  
Its mission is to introduce users to the flexibility and broad capabilities of the 1C platform through a practical, functional, open-source project.

### Description

1C:Jet covers the core processes for managing a small company’s accounting needs.  
It automates purchasing, sales, warehouse and cash operations, advance payments, and profit calculations.  
The application emphasizes clean, readable code and simplicity while providing full functionality for end users.

This repository represents the **regional version for Spanish-speaking countries** of 1C:Jet, featuring localization into Spanish.

---

## 🌎 About this Spanish version

This project aims to help Spanish-speaking developers learn 1C development in their native language.
It includes translated interface texts, documentation, and examples tailored for the local audience.

Development branches:
- `develop-es` — stable release
- `community-es` — open for community contributions
